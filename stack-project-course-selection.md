
# خلاصه طراحی سامانه انتخاب واحد 🎓

---

## 🏗️ معماری کلی

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   Client    │────▶│  Next.js    │────▶│  SQLite     │
│  (Browser)  │◀────│  (API + UI) │◀────│  (Prisma)   │
└─────────────┘     └─────────────┘     └─────────────┘
```

**Stack:**
- **Frontend + Backend:** Next.js (App Router)
- **Database:** SQLite + Prisma ORM
- **UI:** Ant Design (فارسی)
- **Auth:** JWT + Cookie

## 🔌 API Endpoints

```
AUTH:
  POST /api/auth/login    → ورود
  POST /api/auth/logout   → خروج
  GET  /api/auth/me       → اطلاعات دانشجو

COURSES:
  GET  /api/courses       → لیست دروس

ENROLL:
  GET  /api/enroll        → دروس انتخاب شده
  POST /api/enroll        → انتخاب واحد
  DELETE /api/enroll      → حذف درس
```

## ⚙️ منطق انتخاب واحد

```
┌─────────────────────┐
│  درخواست انتخاب درس │
```

## ✅ قابلیت‌های پیاده‌سازی شده

| قابلیت | توضیح |
|---|---|
| **ورود ایمن** | JWT + رمز هش‌شده با bcrypt |
| **انتخاب واحد** | با بررسی ظرفیت، تداخل و تکراری |
| **حذف درس** | با کاهش خودکار ظرفیت |
| **مدیریت ظرفیت** | Transaction برای جلوگیری از خطا |
| **رابط فارسی** | RTL + Ant Design |
| **آمار خلاصه** | تعداد واحد، دروس انتخاب شده |

## 🚀 مراحل اجرا

```bash
# ۱. نصب
npm install

# ۲. آماده‌سازی دیتابیس
npx prisma migrate dev --name init
npx ts-node prisma/seed.ts

# ۳. اجرا
npm run dev

# ۴. دسترسی
# http://localhost:3000
# Username: 1401001
# Password: 123456
```
